#### I. சரியான விடையைத் தேர்ந்தெடு.
1. கீழ்க்கண்டவற்றுள் எது பொருள்களின் நிலையைக் குறிக்கிறது?
   - அ) திட, திரவ, நீர்
   - ஆ) திட, திரவ, வாயு
   - இ) திட, திரவ, மரக்கட்டை
   - ஈ) திட, திரவ, சர்க்கரை
2. கீழ்கண்டவற்றுள் எது திடப்பொருள்?
   - அ) மண்ணெண்ணெய்
   - ஆ) காற்று
   - இ) நீர்
   - ஈ) ஆப்பிள்
3. சணல் இழைகள் எதிலிருந்து பெறப்படுகின்றன?
   - அ) இலைகள்
   - ஆ) தண்டு
   - இ) பூ
   - ஈ) வேர்

#### II. கோடிட்ட இடத்தை நிரப்புக.
1. பருத்தி விளைய ஏற்ற மண் ______________.
2. பருத்தி இழைகளிலிருந்து நூல்களைத் தயாரிக்கும் முறைக்கு ______________ என்று பெயர்.
3. விதை நீக்கல் என்பது விதைகளிலிருந்து ______________ யைப் பிரிக்க உதவுகிறது.
4. செயற்கை இழைக்கு மற்றொரு பெயர் ______________.
5. கம்பளி ஆடைகள் ______________ லிருந்து தயாரிக்கப்படுகின்றன (தாவரம் / விலங்கு).

#### III. பொருத்துக.
| எண் | பொருள் / செயல்முறை | மூலப்பொருள் / முறை |
| :---: | :--- | :--- |
| 1 | நூல் | விதை நீக்கல் |
| 2 | பஞ்சு | நூற்றல் |
| 3 | துணிகள் | மரக்கூழ் |
| 4 | ரேயான் | தண்டு |
| 5 | சணல் | நெய்தல் |

#### IV. சரியா? தவறா?
1. தேங்காயின் வெளிப்புறம் உள்ள பொருள் நார் எனப்படுகிறது.
2. பீன்ஸ் மற்றும் பட்டாணிகள் பயறு வகையைச் சார்ந்தவை.
3. மேஜை ஒரு வீட்டு உபயோகப் பொருள்.
4. இனிப்புச் சோளம் மக்காச்சோள வகையைச் சார்ந்தது அல்ல.

#### V. சுருக்கமாக விடையளி.
1. பருப்பொருள் என்றால் என்ன?
2. திடப்பொருள்களின் ஏதேனும் இரண்டு பண்புகளைக் கூறுக.
3. இயற்கை இழைகள் மற்றும் செயற்கை இழைகளை வேறுபடுத்துக.
4. நூற்பு என்றால் என்ன?
5. சணலின் பயன்கள் யாவை?

#### VI. விரிவாக விடையளி.
1. பருத்தியிலிருந்து ஆடை தயாரிக்கும் முறையை விளக்குக.
2. பருப்பொருள்களின் மூன்று நிலைகளைத் தகுந்த எடுத்துக்காட்டுகளுடன் விளக்குக.
